# Link Me — Rodrigue S. Gandema

Une petite page web (HTML/CSS) qui centralise mes réseaux et mes infos de contact, pensée pour être partagée en un seul lien — notamment sur mon profil LinkedIn.

## 🎯 Objectif

Offrir un point d'entrée unique et soigné vers :
- mes réseaux professionnels (Email, LinkedIn, GitHub)
- mes certifications (via Credly)
- une courte présentation de mon parcours

## 🛠️ Stack

- **HTML5** — structure sémantique
- **CSS3** — mise en page en carte centrée, responsive (media query mobile)
- Police **Poppins** (Google Fonts)

## 📱 Aperçu

La page s'affiche comme une carte centrée sur fond sombre, avec :
- un header (logo + photo)
- une section profil (photo, titre, courte accroche)
- un bloc de liens (Email, LinkedIn, GitHub)
- une section biographie
- une section certifications avec lien vers Credly

## 🚀 Déploiement

Le site est fait pour être déployé simplement via **GitHub Pages** :
1. Push le contenu du dossier `link-me/` à la racine du repo (`index.html` doit être à la racine).
2. Dans les paramètres du repo → **Pages** → choisir la branche `main` et le dossier `/ (root)`.
3. Le site est accessible à `https://<ton-pseudo-github>.github.io/<nom-du-repo>/`.
